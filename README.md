# Tic Tac Toe by AK

A classic Tic Tac Toe game built with HTML, CSS & JavaScript.

**🔗 Live Demo:**  https://tic-tac-toe-by-ak.netlify.app/ 

## Features
- **2 Player Mode** - Play X vs O with friends
- **Turn Management** - Auto switches between X and O
- **Win Detection** - Detects winner using 8 winning patterns
- **Draw Detection** - Shows "It's a Draw!" when board is full
- **Score Tracking** - Keeps count of X and O wins
- **New Game Button** - Resets board and scores
- **Restart Button** - Resets board but keeps scores
- **Box Disabling** - Disables all boxes after win

## Tech Stack
- **HTML5** - Game structure with buttons
- **CSS3** - Styling for grid and buttons
- **JavaScript** - Game logic and DOM manipulation

## Skills Demonstrated
- **DOM Manipulation** - `querySelector`, `querySelectorAll`, `innerText`
- **Event Handling** - Click events for boxes, new game & restart buttons
- **Game Logic** - Win condition checking with patterns array
- **Turn Management** - Boolean flag to switch turns
- **Array Methods** - `forEach`, `Array.from`, `every`
- **Conditional Logic** - if/else for win, draw, and turn checks
- **Loops** - `for...of` loop to check winning patterns
